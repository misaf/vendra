# Resellers

## Land Resellers on Overview and keep operations in row actions
Reseller rows and global search land on ViewReseller. A reseller has no descriptive data of its own, so there is no Edit page — the form is create-only; user-account, subscription, renewal, and offboarding operations belong in the list table ActionGroup, using modal confirmations or slide-overs according to form complexity.
